ABOUT THIS SITE

About Battleplan.wiki

Battleplan.wiki is an unofficial fan-made strategy guide for Battleplan, the upcoming WWII real-time strategy game developed by Foolish Mortals Games Inc. and published by Slitherine Ltd.

This site provides comprehensive coverage of all game features including campaign walkthroughs, unit guides, tactical advice, and the unique command system that defines Battleplan's gameplay.

Our goal is to help players master the game's deep strategic mechanics and historical campaigns before the game's Q3 2026 release.

About the Game

Battleplan is a WWII real-time strategy game that puts players in command of entire divisions during the campaigns of 1944-1945 on the Western Front.

Key features include:

  • • Division-level command with realistic unit hierarchies
  • • Unique battle planning interface for drawing multi-step operations
  • • Massive, historically accurate battlefields spanning thousands of kilometers
  • • 11+ historical campaigns from D-Day to Operation Varsity
  • • Real-time simulation with pause, play, and fast-forward controls

Battleplan is scheduled for release on Steam in Q3 2026.
